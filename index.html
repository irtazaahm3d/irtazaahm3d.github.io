01 / ABOUT

A security mindset,
built through practice.

I’m an undergraduate Information Security engineering student with a growing interest in how digital systems are protected, monitored, and investigated.

My learning so far has included networking and computer fundamentals, web security exercises, digital forensics coursework, and hands-on work with tools such as Wazuh, Docker, FTK Imager, and Parrot Security OS.

I’m especially interested in the defensive side of cybersecurity—understanding security events, investigating suspicious activity, preserving evidence, and improving systems. I’m also exploring web application security to understand vulnerabilities from a practical perspective.
